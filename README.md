## What Is Aplikasi Acak Kelompok?

Aplikasi Acak Kelompok is a web application that assigns participants to groups using randomization. It replaces time-consuming manual arrangements with a simple process for producing groups quickly.

The tool is intended for learning and training environments where participants need to be distributed fairly. Teachers, lecturers, trainers, and facilitators can use it to prepare collaborative activities without repeatedly organizing names by hand.

- Minimizes repetitive manual arranging
- Works well for classroom activities and training sessions

## How to Use

1. Start the application in a modern web browser.
2. Add or prepare the participant names.
3. Run the randomization command to generate groups.
4. Check the results, then randomize again whenever a new arrangement is required.

For repeated classes or workshops, update the participant list between sessions and generate a fresh grouping for each activity.
